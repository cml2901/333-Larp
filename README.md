# Eredrin Abilities (NeoForge 1.21.1, аддон к Fantasy Armor)

Работает только при полном сете Эредина (fantasy_armor:eredrin_helmet/chestplate/leggings/boots).

- Правый Alt - радиальное меню (клик по сектору или клавиши 1/2/3)
- X - выполнить выбранную способность (кулдаун 2 сек)
  1. Телепорт за спину цели, на которую смотришь
  2. Телепорт на прицел (до 40 блоков)
  3. Ледяные шипы: при попадании Слепота V + Слабость V на 30 сек

Если в репозитории уже есть свой build.gradle / gradlew - оставь свои, скопируй только `src/`.
Версии neo_version и moddev при необходимости поправь под свой проект.
